Privacidade

Última atualização: 7 de outubro de 2026.

O Pixelarte foi projetado para funcionar principalmente no seu próprio navegador. Esta página explica quais dados o aplicativo usa atualmente e como eles são armazenados.

Projetos e imagens

Os projetos criados no Pixelarte, incluindo imagens importadas, gráfico gerado, configurações e andamento das carreiras, ficam armazenados localmente no navegador por meio do IndexedDB.

O Pixelarte não possui conta de usuário nem envia esses projetos para um servidor próprio. Ao usar Exportar, o arquivo é gerado no seu dispositivo.

Armazenamento local

O aplicativo usa recursos locais do navegador para funcionar:

  • IndexedDB para salvar projetos e progresso;
  • localStorage para lembrar qual projeto estava aberto;
  • Cache do Service Worker para permitir uso offline e atualização da PWA.

Esses dados podem ser removidos ao excluir projetos dentro do Pixelarte ou ao apagar os dados do site/PWA nas configurações do navegador.

Conectividade

Para distinguir uma conexão real com a internet de uma conexão apenas com a rede local, o Pixelarte faz uma requisição técnica a um serviço externo de verificação de conectividade. Essa verificação serve para atualizar o indicador Online/Offline e controlar recursos que dependem da internet.

Publicidade

A versão atual possui espaços reservados para publicidade, mas a integração com uma rede de anúncios está desativada. Enquanto ela permanecer desativada, o Pixelarte não carrega anúncios de terceiros por esses espaços.

Antes de qualquer ativação de publicidade personalizada ou tecnologia equivalente, esta política e os mecanismos de consentimento serão atualizados conforme necessário.

Analytics e rastreamento

O Pixelarte não possui, nesta versão, uma ferramenta própria de analytics ou rastreamento de comportamento integrada ao aplicativo.

Hospedagem

A versão pública do Pixelarte é hospedada no GitHub Pages. Como provedor de hospedagem, o GitHub pode tratar informações técnicas de acesso de acordo com suas próprias políticas.

Exclusão de dados locais

Você pode usar Excluir projeto para remover um projeto específico. Para apagar todos os dados locais do Pixelarte, use os controles de dados do site/PWA disponíveis no navegador ou sistema.

Código aberto

O Pixelarte é open source. O código-fonte público permite verificar como o aplicativo armazena e processa os dados locais.

Alterações desta política

Esta política pode ser atualizada quando novos recursos forem adicionados, especialmente publicidade, analytics, serviços externos ou formas adicionais de armazenamento.
